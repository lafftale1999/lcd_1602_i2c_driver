LCD_WRITE_STATUS lcd_1602_write_bottom ( i2c_master_dev_handle_t handle,
const char * str )

Writes a string to the bottom row without changing the top row.

Any remaining space on the row is filled with blanks, so old text on the row is erased. Writing stops at '\0', '
' or the end of the row.

Parameters
handleThe device handle used to writing on the i2c bus
strThe string to write
Returns
LCD_WRITE_FINISHED if the whole string fit, LCD_TOO_LONG_STRING if it was truncated, LCD_WRITE_INTERRUPTED if communication on the i2c bus failed.
